# Fuzzy Macro

The desktop app for the macro. The user starts and stops it, watches what it is doing, and changes its settings.

## Home tab

**Panel**:
A titled box on the Home tab: Tasks, Logs, Vic Hop statistics or Planter Timers.
_Avoid_: widget, card, window

**Layout**:
How the Home tab's panels are arranged: which side Logs sits on and how much room Tasks and Logs get. The user chooses it, and the original arrangement is the default.
_Avoid_: view, workspace

## Display

**1080p display mode**:
An optional macro mode that gives one Roblox client a 1920x1080 game content area on a non-Retina virtual display for consistent screen detection.

**Virtual display**:
The software-created monitor that hosts Roblox while 1080p display mode is active.

**Game content area**:
The area displaying the game, excluding window borders and desktop controls. Its dimensions are distinct from the virtual display's dimensions.
