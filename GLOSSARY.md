# Fuzzy Macro

## Language

**1080p display mode**:
An optional macro mode that gives one Roblox client a 1920x1080 game content area on a non-Retina virtual display for consistent screen detection.

**Virtual display**:
The software-created monitor that hosts Roblox while 1080p display mode is active.

**Game content area**:
The area displaying the game, excluding window borders and desktop controls. Its dimensions are distinct from the virtual display's dimensions.
