# Fuzzy Macro

Fuzzy Macro automates Bee Swarm Simulator. These terms describe the configurations users manage.

## Language

**Profile**:
A named configuration containing macro settings and field settings. The current profile is the configuration selected for use.

**Field settings**:
The gathering options assigned to a Bee Swarm Simulator field within a profile.

**Gather pattern**:
A named movement routine used while gathering in a field.
_Avoid_: Gather profile
