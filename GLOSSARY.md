# Fuzzy Macro

The desktop app for the macro. The user starts and stops it, watches what it is doing, and changes its settings.

## Home tab

**Panel**:
A titled box on the Home tab: Tasks, Logs, Vic Hop statistics or Planter Timers.
_Avoid_: widget, card, window

**Layout**:
How the Home tab's panels are arranged: which side Logs sits on and how much room Tasks and Logs get. The user chooses it, and the original arrangement is the default.
_Avoid_: view, workspace
